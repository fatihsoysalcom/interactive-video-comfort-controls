# Interactive Video Comfort Controls

This example demonstrates interactive controls for a YouTube video player, simulating features that enhance immersion and eye comfort. It reflects how VR platforms like Meta Quest might transform video consumption by offering personalized viewing experiences and adjustments for eye health, contrasting with traditional flat-screen viewing. Users can toggle a "Theater Mode" for a more immersive feel and a "Night Mode" along with brightness/contrast sliders to adjust for eye comfort.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
